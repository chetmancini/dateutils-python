# DateUtils Python brand concepts

Three mark + wordmark ideas are shown in [logo-concepts.png](logo-concepts.png):

1. **Calendar + code** — a calendar with code brackets. Navy and teal connect date operations with developer tooling.
2. **Orbit** — a lowercase “d” and clock hand with an amber satellite. A broader time and timezone identity.
3. **Workweek** — a stepped calendar grid. Green highlights suggest business-day calculations. Selected direction; used for the README banner and current logo.
